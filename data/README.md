# Data

`openings.tsv`: 3,865 named opening lines (ECO code, name, moves), merged from the five files `a.tsv` to `e.tsv` of
https://github.com/lichess-org/chess-openings (checked 2026-11-24). The data set is released under CC0 (public domain
dedication); it is credited here as a courtesy. Used for the "Book" move sign and the opening name in the web UI.
